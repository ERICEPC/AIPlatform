# v4 新增与改动的接口（2026-11-08）

前缀均为控制台接口 `/console/api`（`rx-config.js` 的 `apiBase`）。服务端按登录账号的角色与管理范围校验；前端只负责不展示无权操作。时间字段为 ISO 字符串（Agent Teams 原接口仍为 Unix 秒）。类型定义以 `src/api/*.ts` 为准。

## 账号与权限 · `src/api/access.ts`

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/account/permissions` | 当前账号的角色（developer / admin / super_admin）、管理范围 scopes（部门 / 业务 / 工作流）、组织授权 org_grants、可统一身份登录的 xBuddy、租户 |
| POST | `/logout` | 退出登录 |
| GET | `/sso/providers` | 统一身份登录方式（飞书、xBuddy 统一身份），返回跳转地址 |
| GET | `/setup` | 初始化状态（原接口；首个账号为超级管理员） |

## 待我确认 · `src/api/inbox.ts`

| GET | `/inbox?type=&state=pending\|done` | 智能体交给人确认的事项：需要决定什么、为什么不能继续、依据、可选方案及影响、确认后发生什么 |
| --- | --- | --- |
| POST | `/inbox/{id}/actions` | `{ action: confirm \| confirm_edit \| supplement \| return \| transfer, option, comment, transfer_to }`；一次确认只授权该事项，重复提交幂等；执行状态单独返回 |

| PATCH | `/personal-assistant/skills/{id}` | 启用 / 停用 |

## 平台 MCP（一切皆 MCP）· `src/api/mcp-hub.ts`

X 平台的每项能力以 MCP 服务开放（Streamable HTTP，经 MCP 网关统一鉴权、限流与审计）。前端只做目录、试调用与客户端配置生成；MCP 服务本身由后端实现。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/mcp-hub/servers` | 平台 MCP 服务与工具：`id`、端点、依赖的技术栈组件 `backed_by`、调用方 `consumers`、工具（名称、参数、风险 read / write / external、示例） |
| POST | `/mcp-hub/servers/{id}/tools/{tool}/try` | 用当前账号试调用；写入与对外工具只做预演，返回 `audit_id` |
| GET | `/mcp-hub/client-config?consumer=` | 生成 MCP 客户端配置（个人助理 · 编排引擎 · SalesBuddy · ProjectBuddy · 客服 · HR）；令牌以占位符给出 |

十个服务：`rx-agents` 智能体 · `rx-workflows` 工作流团队 · `rx-knowledge` 知识库 · `rx-memory` 记忆 · `rx-skills` Skills · `rx-data` 业务数据 · `rx-models` 模型 · `rx-inbox` 待我确认 · `rx-desktop` 桌面连接器 · `rx-devkit` 开发套件（加速器与脚手架）。

鉴权约定：

- 个人助理（DeepSeek Harness）与编排引擎：服务令牌 ＋ 请求头 `X-RX-On-Behalf-Of: <用户 id>`，每次调用按该用户权限重新校验。
- xBuddy：应用令牌（管理后台「应用接入」签发）＋ 最终用户令牌（统一身份），只能调用该应用开放能力对应的服务与工具。
- 风险为写入、对外的工具，按策略转「待我确认」，人确认后才执行；所有调用记审计。

## 与 ProjectBuddy 一体（2026-11-08）

ProjectBuddy 与 X 平台一个账号、一套权限，登录一处另一处免登录；ProjectBuddy 的 Buddy 应用开发经 ProjectBuddy 后端调 X 平台。详见 ProjectBuddy 工程 `app/frontend/docs/后端连接与API说明.md`。X 平台需要提供：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/sso/tickets` | 服务令牌 ＋ `X-RX-On-Behalf-Of`，换一次性免登录票据（60 秒、一次有效、绑定用户与目标路由） |
| GET | `/sso/consume?ticket=` | 前端消费票据、建立同一用户的会话并跳到目标页 |
| PATCH | `/stack/scaffold/templates/{id}` | 见上，模板发布到 ProjectBuddy |

前端：顶栏「ProjectBuddy」免登录入口，地址在 `public/rx-config.js` 的 `projectbuddyUrl`。
