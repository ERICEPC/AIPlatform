- frontend/src：当前 React 页面、组件、样式和 API 适配层。
- frontend/public：Logo、浣熊头像、技能目录等静态资源。

- MANIFEST.sha256：源码文件校验清单。

## 安装与构建
使用 Node.js 22.12+ 或 Node.js 24，以及 pnpm 10。

```bash
cd frontend
corepack enable
pnpm install --frozen-lockfile
cp .env.production.example .env.production
VITE_BASE=/new-ui/ pnpm build
pnpm preview
```

生产产物为 dist/，预览入口 http://127.0.0.1:5181/new-ui/ 。
开发模式运行 pnpm dev；默认使用 mock，只有提供 mock 实现的页面支持演示，不能认为全部功能离线可用。真实模式需要配置 VITE_API_MODE=live 并连接对应后端。

## 部署路径与接口
当前 vite.config.ts 默认 base 是 /new-ui/。将 dist/ 部署到网站 /new-ui/，即使首页 / 复用该 index.html，也必须保留 /new-ui/assets/ 的访问映射。部署到根目录时必须重新以 VITE_BASE=/ 构建，并把完整 dist 放到根目录。不要只改 HTML 或只复制 index.html。

.env.production.example 包含公开接口配置，不含模型密钥。VITE_ 变量会编入浏览器脚本，不应写入服务端密钥。
默认控制台接口 /console/api，采用 Cookie 会话和 CSRF；知识库代理 /console/api/knowledge-bridge。建议通过同域反向代理接入当前配套后端。VITE_KB_APP_URL 可覆盖源码中的历史知识库跳转地址。

这是前端交付包，不包含数据库、用户数据、模型凭据、后端 API、DeepSeek Harness 服务与 Docker 镜像。个人助手、智能体协同、Agents、知识库、Skills、MCP 的真实功能依赖配套服务；仅部署本包不能迁移整个平台。

## 主要代码入口
- src/App.tsx：页面路由与入口
- src/pages/Assistant.tsx、Config.tsx：个人助手对话与配置

不包含 node_modules、旧 dist、私有环境文件与版本库元数据。源码未做功能性改写。
