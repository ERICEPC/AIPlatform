# Governance API contract (frontend <-> old Flask backend)

All paths are under `/console/api` (Flask-RESTX `console_ns`), JSON, cookie session + X-CSRF-Token (existing `@auth` decorator in controllers/console/agent/personal.py gives `(session, tenant_id, current_user)`).
Errors: werkzeug exceptions → `{message}` with 400/403/404/409/503. All user-facing messages in Simplified Chinese.

## Types

```ts
type Role = 'super_admin' | 'dept_head' | 'member'
type Scope = 'private' | 'department' | 'public'          // API value. 'public' = whole workspace (tenant). Backend may store 'workspace' internally in rx_releases for back-compat but MUST emit 'public'.
type ResourceKind = 'agent' | 'team' | 'skill' | 'mcp'
type RequestState = 'pending' | 'approved' | 'rejected' | 'withdrawn' | 'returned' | 'failed' | 'stale'
type Assignee = 'dept_head' | 'super_admin'

type Authority = {
  role: Role
  account_id: string
  name: string
  department_id: string | null          // a member belongs to ONE department (first row of rx_department_members)
  department_name: string | null
  head_department_ids: string[]         // departments this user directly heads
  scope_ids: string[]                   // super: all dept ids; dept_head: head depts + descendants; member: []
  departments: { id: string, name: string, parent_id: string | null }[]   // all departments (labels)
  permissions: string[]                 // compat. super: ['release.approve','org.members','org.manage','audit.view','ops.view','admins.manage']; dept_head: ['release.approve','org.members','audit.view','ops.view']; member: []
  enabled: boolean
}

type ShareRequest = {
  id: string
  code: string                          // 申请编号, e.g. 'RQ-20261113-1a2b' (derive from created_at + id prefix)
  kind: ResourceKind
  resource_id: string
  resource_name: string
  version: string                       // '' when unknown (agent: active snapshot version 'v3'; team: 'v'+published version)
  applicant_id: string
  applicant_name: string
  applicant_department_id: string | null
  applicant_department_name: string | null
  requested_scope: 'department' | 'public'
  approved_scope: 'department' | 'public' | null
  department_id: string | null          // applicant's department at submit time
  department_name: string | null
  current_scope: Scope                  // the resource's CURRENT visibility at read time
  note: string
  state: RequestState
  assignee: Assignee                    // department request → 'dept_head' (until forwarded); public → 'super_admin'
  forwarded_by_name: string | null
  forwarded_at: string | null           // ISO
  forward_comment: string | null
  reviewer_name: string | null
  comment: string                       // decision comment ('' if none)
  created_at: string                    // ISO
  decided_at: string | null
  can_decide: boolean                   // for the current viewer
  can_forward: boolean                  // for the current viewer
}

type ApprovalDetail = ShareRequest & {
  resource: {
    description: string
    url: string                         // frontend hash route, e.g. 'agents/<id>', 'teams/<id>', 'skills/local', 'integrations/mcp'
    owner_name: string
    agent?: { model: string, prompt: string, tools: string[], skills: string[], knowledge: string[] }
    team?: { leader: string, members: string[] }
    skill?: { files: string[], instructions: string }                 // SKILL.md text (may be truncated ~2000 chars)
    mcp?: { server_url: string, tools: string[], authorized: boolean } // server_url MASKED (keep scheme+host, mask path/query/token)
  }
  checks: { level: 'ok' | 'warn' | 'risk', text: string }[]          // 发布前检查
  dependencies: string[]                                               // 资源依赖
  changes: string[]                                                    // 版本变化
  timeline: { action: 'submit' | 'forward' | 'approve' | 'reject' | 'withdraw', actor_name: string, at: string, comment: string }[]
}

type ResourceShare = {
  kind: ResourceKind
  resource_id: string
  name: string
  visibility: Scope
  department_id: string | null
  department_name: string | null
  can_manage: boolean                   // caller is the owner
  owner_id: string
  published: boolean                    // agent: active_config_is_published; team: published_id; skill: latest_published_version_id; mcp: authorized
  request: ShareRequest | null          // latest request for this resource (any state)
  updated_at: string | null
}
```

## Rules (must match the spec §0–§3)
- Roles: super_admin = rx_admin_assignments role_id 'role-super'. dept_head = has ≥1 row in new table rx_department_heads. Else member. (Old custom 'admin' assignments are ignored for authority.)
- Department request: target = applicant's department. Applicant without department → 409 `请联系超级管理员分配部门`.
- Public request: only super_admin can approve. Department request: approvable by a dept head whose scope_ids contains the applicant's department (assignee must still be 'dept_head'), or any super_admin.
- Nobody approves their own request (403 `不能审批自己提交的申请`). A dept head facing own request can only forward.
- Approve may narrow public → department (scope param), never widen. Reject requires comment.
- Forward: dept head only, pending department request with assignee 'dept_head' in their scope; comment required. Sets assignee='super_admin', forwarded_by, forwarded_at, forward_comment. The dept head can no longer decide it.
- Private: immediate, no approval. Revokes department/public sharing and auto-withdraws any pending request.
- One pending request per resource (409). Requesting a scope not larger than current → 409 (`当前已是该范围`). Publish prerequisites: agent published, team published, mcp authorized, skill published → else 409 with message (`草稿不能共享，请先发布智能体` / `草稿不能共享，请先发布智能体团队` / `请先完成 MCP 服务授权，再申请共享` / `请先发布 Skill，再申请共享`).
- Approval list visibility: super sees all. dept head: pending = pending & assignee dept_head & requested department & applicant dept in scope; done = non-pending requests in scope (requested department) + requests they forwarded (still pending, assignee super_admin).

Audit categories (Chinese strings, used both as `category` value and filter): 发布申请 (submit / withdraw / 改为仅个人), 审批处理 (approve / reject / forward), 权限变更 (grant/revoke super admin, set/remove dept head), 组织变更 (dept create/rename/move/delete, member department change), 技术栈配置, 登录. Only human actions; no app calls or agent runs.
Dept-head audit scope: actor belongs to a scope dept OR the record's department_id is in scope.
