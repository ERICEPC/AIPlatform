## 一、改了什么（对应 6 项需求）

| # | 需求 | 实现 |
|---|---|---|
| 1 | 申请共享：仅个人 / 部门 / 公共空间 | 智能体、智能体团队、Skills、MCP 与工具统一用一个共享弹窗。仅个人立即生效（并撤回审批中的申请）；部门＝申请人所在部门，由部门负责人或超管审批；公共空间只有超管能批 |
| 2 | 我的发布 | 列出本人创建的全部四类资源（不论范围），显示当前可见范围和最近一次申请状态；审批后状态同步 |
| 3 | 发布审批页改版 | 通过 / 驳回 / 转审超级管理员、批准范围、意见放在顶部固定栏；申请信息和资源概要、发布前检查、依赖、版本变化直接显示，不用跳转；去掉「可用范围」标签行 |
| 4 | 组织与审批规则 | 超管：李鹏程、周玮、叶源；部门负责人由超管设置（一个部门可多位）；部门负责人可转审给超管；任何人不能审批自己的申请；至少保留一位超管。组织与成员页改为「成员与部门 / 部门负责人 / 身份来源」 |
| 5 | 业务空间 | 改为按部门看智能体用量：调用次数、调用人数、各模型 Token、最近调用，7 / 30 天切换；去掉原资源配置表单。智能体按所有者所在部门归属；超管看全部，部门负责人看本部门（含下级） |
| 6 | 侧边栏与审计日志 | 去掉「平台」分组，隐藏应用接入（xBuddy）和 AI 技术栈组件（路由保留，仅超管可直达）；审计只记人的操作，列为 时间 / 操作人 / 对象 / 内容 / 部门 / 结果，支持按操作人、类别、部门、结果、时间、关键字筛选 |
| — | 统一身份登录（共享 Auth） | OIDC 授权码 + PKCE，BFF 模式；已有账号先登录后「绑定企业统一身份」，不按邮箱合并；租户白名单 |

完整规格见 [设计规格.md](设计规格.md)，前后端接口见 [接口契约.md](接口契约.md)。

## 四、部署到盒子（https://10.151.113.125:21190）

1. 部署本分支的 API 与前端，执行上面的数据库变更。
2. 首次部署：若当前工作空间还没有超管，需在 `rx_admin_assignments` 手动插入第一位超管（role-super），其余在页面里设置。
3. 统一身份配置（API 服务环境变量，密钥只放私有文件）：

```
PARTNER_AUTH_ISSUER=http://10.151.113.125:9088
PARTNER_AUTH_CLIENT_ID=<Auth 提供>
PARTNER_AUTH_CLIENT_SECRET_FILE=<私有密钥文件路径>
PARTNER_AUTH_REDIRECT_URI=https://10.151.113.125:21190/console/api/auth/partner/callback
PARTNER_AUTH_WORKSPACE_ID=<平台工作空间 ID>
PARTNER_AUTH_ALLOWED_TENANTS=<sensetime-CNI生态渠道在 Auth 中的 tenant_id>
```

4. 接口：`GET /console/api/auth/partner/status`、`GET /console/api/auth/partner/login[?bind=1]`、`GET /console/api/auth/partner/callback`。未配置时登录返回 503「统一身份未配置」。
5. 已有账号的同事：先用账号密码登录 → 左下角账号菜单「绑定企业统一身份」→ 之后可直接统一身份登录。

## 六、本地体验（演示模式，不需要后端）

```bash
cd frontend-20261112-preview
pnpm install --frozen-lockfile
pnpm exec vite --host 127.0.0.1 --port 5184
```

打开 http://127.0.0.1:5184/new-ui/#login → 「演示账号」。演示账号：周莹（成员）、蒋磊（北区东区负责人）、李鹏程 / 叶源（超管）。左下角账号菜单可切换账号。

建议路径：周莹在「智能体」申请共享到部门 → 切换蒋磊在「管理后台 › 发布审批」通过或转审 → 切换李鹏程看全部申请、把公共空间收窄为部门 → 切回周莹看「我的发布」状态更新。

## 七、已知限制与待办

- 统一身份：前台活动上报（`/v1/auth/activity`）、浏览器全局退出、换号尚未实现，联调期间补齐。
- 会话复核间隔 60 秒；Auth 或 Redis 暂时不可用时保持登录。
- 通过统一身份新建的成员在工作空间中是 normal 角色，智能体团队模块需要 owner / admin / editor，故新成员暂不能使用团队。
- 部门数据在平台内维护；Auth 能提供部门树后改为同步。
- 演示模式下 Skills「本地」列表为空，Skill 共享通过「我的发布」「发布审批」中的预置数据演示。
